用法 / How to use
1. 复制下面的 raw 链接，在 v2rayN / v2rayNG / Hiddify / NekoRay / V2Box 里「从 URL 添加订阅」。
   Copy the raw URL and add it as a subscription in your client.
2. 短名单 ≤ 300 条，先测延迟再排序，客户端不易卡顿。
   The short list is capped so the client stays responsive; test ping and sort afterwards.
3. 连不上就刷新订阅、换节点；免费节点随时失效，这是正常现象。
   If a node fails, refresh and pick another — free nodes die constantly, that is expected.
4. 「完整」名单节点多，可能让客户端卡顿或崩溃。
   The full lists may lag or crash weaker clients.
